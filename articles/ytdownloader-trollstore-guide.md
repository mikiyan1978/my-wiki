# YTDownloader TS(TrollStore版)インストールガイド

YouTube動画をダウンロードできる自作アプリ **YTDownloader** のTrollStore版。脱獄なしで動く、公式YTDownloader(脱獄版)とは**完全に別アプリ**として動作します。bundle ID・URLスキーム・保存先フォルダ・Cookieファイルがすべて独立しているため、脱獄版と同時にインストールしても干渉しません。

English: [YTDownloader TS (TrollStore) Guide](#/view/ytdownloader-trollstore-guide-en)

リリース: [GitHub Releases](https://github.com/mikiyan1978/sileo-repo/releases/tag/ytdownloader-trollstore-v1.0)

---

## 必要なもの

- **TrollStore** がインストール済みのiOS端末
- iOS 14以降
- Wi-Fi接続(初回のランタイムダウンロード用、約120MB)

---

## STEP 1: .tipaをダウンロード

[GitHub Releases](https://github.com/mikiyan1978/sileo-repo/releases/tag/ytdownloader-trollstore-v1.0) から `YTDownloaderTrollStore.tipa` をダウンロード。

- iPhone/iPadのSafariで直接開いてダウンロード、または
- パソコンでダウンロードしてAirDropでiPhoneへ送る(「ファイル」アプリの「このiPhone内」などに保存)

---

## STEP 2: TrollStoreでインストール

1. **TrollStore** アプリを開く
2. 右上の **「+」** をタップ
3. ダウンロードした `YTDownloaderTrollStore.tipa` を選択
4. インストール完了後、ホーム画面に **「YTDownloader TS」**(紫系アイコン)が追加される

> Safariから直接開いた場合は「TrollStoreで開く」を選べばそのままインストール画面に進みます。

---

## STEP 3: 初回起動時のランタイム設定

YTDownloader TSはPython/yt-dlp/Node製の実行環境を内部で使っており、**初回起動時に一度だけ**この一式(約120MB)をダウンロード・設定する必要があります。

1. アプリを開くと「ランタイム一式が必要です」という画面が出る
2. **「インストール開始」** をタップ
3. ダウンロードが進み、展開・設定が自動で行われる
4. **ここで「この端末でダウンロード機能を正しく動かすには、もう一段階の設定が必要です」という画面が出たら**:
   - 内容を読んで **「続ける」** をタップ
   - 自動的に **TrollStoreアプリに切り替わる**
   - TrollStoreの確認画面が出たら **「Install」** をタップ
   - 数秒でYTDownloader TSが**自動的に再起動**して戻ってくる

> 設定が終わった実行環境は、アプリの更新でも消えないデータ領域に保存されます。次回以降の更新で、この手順をやり直す必要はありません。
> この「TrollStoreに切り替わって Install をタップする」操作は、TrollStoreが新しいアプリを正式にインストールするときの標準的な確認ステップです。見慣れない画面に切り替わって驚くかもしれませんが、問題ありません。指示通り進めれば自動的に元のアプリに戻ります。

設定が終わると通常の画面(動画URLを貼り付けてダウンロードする画面)が使えるようになります。

---

## 使い方のポイント

- **通知の許可**: 最初のダウンロードを開始するときに「通知を許可しますか」と出ます。許可すると、ダウンロードの完了・失敗が通知で届きます。
- **画面ロック・他のアプリ使用中でも続く**: ダウンロード中はアプリが背面でも動き続け、キューに入れた動画も順に処理されます(ダウンロード中だけ、無音のオーディオを再生してアプリを起こしています。他の音楽は止まりません)。
- **コピーしたURLをすぐダウンロード**: 動画のURLをコピーしてこのアプリを開くと、開始ボタンが「コピーしたURLをダウンロード」に変わります(コピーの中身は、ボタンを押すまで読みません)。
- **YouTubeの仕様変更でダウンロードできなくなったとき**: アプリの「設定」→ 一番下の「ダウンロードエンジン(yt-dlp)」→ **更新を確認**。アプリの入れ替えや、前述のTrollStoreでの再署名は不要です。起動時にも1日1回、自動で確認します。

## 機能

### 画質と形式

- 画質は「毎回選ぶ」「最高画質」「1080p」「720p」「音声のみ」から、既定を「設定」で決められます。
  - 既定を決めていると、共有メニューなど**ほかのアプリからリンクを渡したとき**は、安全のため「このリンクをダウンロードしますか?」と確認が出ます(「ダウンロード」を押すと、既定の画質で始まります)。アプリの中で貼り付けたときは、確認なしで始まります。
- **音声のみ**: MP3(タイトル・アーティスト・ジャケット画像つき)またはFLAC(タイトル・アーティストつき)。
- **字幕つき**: 画質の選択画面の「字幕付きダウンロード」で、字幕を動画に埋め込んだMKVになります。字幕の言語は「設定」→「字幕の言語」で、日本語+英語(既定)/日本語のみ/英語のみから選べます。全言語を取る選択肢は、YouTube側の制限で失敗するため用意していません。

### チャプター

動画にチャプターがあれば、自動でファイルに書き込まれます(MP4・MKV・WebM)。チャプターが無い動画では何も追加せず、時間もかかりません。

### スポンサー部分(SponsorBlock)

「設定」→「スポンサー部分(SponsorBlock)」で選びます。既定はオフです。

| 設定 | 動作 |
|---|---|
| オフ | 何もしない |
| チャプターで印を付ける | スポンサー紹介・自己宣伝・高評価のお願いの区間が、チャプターとして入る(動画は変わらない) |
| カットして取り除く | その区間を動画から切り取る |

- 区間は有志が登録した公開データベース(sponsor.ajay.app)から取得します。動画IDそのものではなく、ハッシュの先頭4文字だけを送ります。
- 「カット」は、再エンコードをせず、動画をそのまま切ってつなぎます。そのため速く、画質も落ちません。H.264のMP4(互換性優先モードなど)では、通常のつなぎ方が失敗することがありますが、その場合は自動で別の方法に切り替えて切ります。切れた位置は、キーフレームの都合で数十ミリ秒〜数秒ずれることがあります。それでも切れなかったときだけ、切らずにそのまま保存して「完了しました(スポンサー部分のカットは失敗)」と表示します。

### ライブ配信の録画

配信中のライブのURLを渡すと、録画になります。

- 画面には「● 録画中」、録画時間、書き込み済みの容量が出ます(配信は終わりが決まっていないため、%や合計は出ません)。
- 右上のボタンは「■ 停止して保存」。押すと数秒で録画が止まり、MP4として保存されます。
- 空き容量が少なくなると、自動で停止して保存します。
- 録画中にアプリが終了されると、続きから録画することはできません。

### 途中で止まったダウンロードの再開

アプリが終了されても、待機中のキューと、ダウンロード中だった1件は保存されています。次に起動したとき、

- キューは**一時停止の状態で復元**されます(件数が多くても勝手には始まりません)。
- 中断された1件は「続きから再開しますか?」と確認が出ます。「続きから再開」を押すと、途中から続きます(最初からやり直しにはなりません)。

### YouTube以外のサイト

yt-dlpが対応しているサイトのURLも、同じように渡せます(動作を確認したのは、ニコニコ動画、SoundCloud、Dailymotion、TikTokです)。

- **プレイリスト・アルバム・チャンネルのURL**は、1件ずつキューに入ります。SoundCloudのセットや、YouTubeのチャンネルページも同じです。
- 音声だけのサイト(SoundCloudなど)は「音声のみ」と表示され、M4Aなどで保存されます。
- 同じ動画をもう一度渡すと、保存済みなら「すでにダウンロード済み」と出ます。
- ログインが必要な動画(ニコニコの会員向け、Vimeoの一部、X、Instagramなど)は、下の「ログインが必要なサイト」の設定で取得できることがあります。

#### ログインが必要なサイト

「設定」→「ログインが必要なサイト(YouTube以外)」で選びます。この端末のSafariなどに保存されたログイン情報(Cookie)のうち、**ダウンロードするサイトの分だけ**を使います(先にSafariでそのサイトにログインしておいてください)。YouTubeには使いません。

| 設定 | 動作 |
|---|---|
| 使わない(既定) | ログイン情報を使わない |
| 必要なときだけ自動 | まずログインなしで取得し、サイトが「ログインが必要」と返したときだけ、1回やり直す。公開動画ではアカウントを使わない |
| 常に使う | YouTube以外では毎回ログイン情報を付ける |

- 迷うなら「必要なときだけ自動」がおすすめです。「常に使う」は、サイトによってアカウントが制限されたり、期限切れのログインのせいで取得できなくなったりすることがあります。
- ログインが必要な動画で失敗したときは、画面と通知で、この設定を案内します。

### ライブラリ

- **プラットフォームごとの切り替え**: 2種類以上のサイトからダウンロードしていると、上部に「すべて | YouTube | ニコニコ | SoundCloud …」のタブが出ます。選んだサイトの動画だけが、チャンネルごとに並びます(選んだタブは覚えています)。保存先のフォルダは1つのままです。
- 上部に、ダウンロード合計の容量と端末の空きが出ます。
- 動画ごとの共有ボタンから、**写真に保存**(MP4など対応形式のみ)や、**ファイルに保存・共有**ができます。

## よくあるトラブル

| 症状 | 原因・対処 |
|---|---|
| 「ランタイム一式」画面に何度も戻ってくる | ダウンロードが完了する前にアプリを閉じた可能性。もう一度「インストール開始」から試す |
| 「自動署名がタイムアウトしました」と表示される | TrollStoreの確認画面を見逃していないか確認。再試行すれば通常は解決する |
| YouTubeの共有メニューからYTDownloader TSを選んでも脱獄版が開く | 両者は別のURLスキームを使うため通常は起きないはずだが、もし起きた場合はYTDownloader TSを一度再インストールしてみる |
| アプリを更新したら「ランタイム一式が必要です」に戻った | **この版より前の版から、この版に更新するときだけ**、1回だけ起きます(古い版は、実行環境をアプリの中に置いていたため、更新で消えます)。もう一度STEP 3をやり直してください。設定や保存した動画は消えません。**この版以降は、更新しても実行環境が残る**ので、STEP 3のやり直しは不要です |
| ダウンロード中のサイズ表示が「129.4 MB」だけで、合計が出ない | 合計が事前に分からない形式では、実際に書き込んだ容量だけを表示し、完了時に合計が確定する(YouTubeの分割形式は、最初から合計も出る) |
| ダウンロードがうまくいかない(動画が取得できない) | ランタイム設定が正しく完了しているか確認(STEP 3を再確認)。YouTube側の仕様変更が原因のこともある |

## 脱獄版との違い

| | 脱獄版(Sileo配布) | TrollStore版(本ガイド) |
|---|---|---|
| 必要環境 | palera1nなどの脱獄 | TrollStoreのみ(脱獄不要) |
| ダウンロード高速化(aria2c) | ◯(apt経由) | ◯(アプリに同梱) |
| 初回セットアップ | ランタイムダウンロードのみ | ランタイムダウンロード + (環境により)TrollStoreでの再署名確認 |
| 保存先・Cookie・アイコン | 脱獄版専用 | TrollStore版専用(完全に分離) |

機能面はほぼ同一。脱獄していない端末で使いたい場合はTrollStore版を選んでください。
