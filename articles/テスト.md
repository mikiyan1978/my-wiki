# 全端末対応/脱獄状況

[iPhone Development Wiki](https://www.theiphonewiki.com/)や各ツールの公式ドキュメントを参考にした、脱獄(Jailbreak)ツールごとの対応端末・iOSバージョン・使用脆弱性のまとめです。

> ⚠️ 脱獄シーンは脆弱性の発見・修正により頻繁に変化します。実行前に必ず各ツールの公式GitHub/Discordで最新のサポート状況を確認してください。

---

## 1. checkm8 系(BootROM脆弱性)

**checkm8**は2019年に[axi0mX](https://twitter.com/axi0mX)が公開したBootROMレベルの脆弱性で、A5〜A11チップに存在します。BootROMはハードウェアに焼き込まれているため**Appleは原理的にパッチ不可能**という特徴があります。

- 詳細解説: [theiphonewiki.com – Checkm8](https://www.theiphonewiki.com/wiki/Checkm8)
- 実装リポジトリ: [axi0mX/ipwndfu (GitHub)](https://github.com/axi0mX/ipwndfu)

### 対応チップ・端末
| チップ | 端末 |
|---|---|
| A5 | iPhone 4s, iPad 2/3, iPad mini (1st) |
| A6 | iPhone 5 / 5c |
| A7 | iPhone 5s, iPad Air (1st), iPad mini 2/3 |
| A8 | iPhone 6/6 Plus, iPad mini 4 |
| A9 | iPhone 6s/6s Plus, iPhone SE (1st) |
| A10 | iPhone 7/7 Plus, iPad (6th/7th) |
| A11 | iPhone 8/8 Plus, iPhone X |

### checkm8ベースの脱獄ツール

#### checkra1n
- 公式サイト: [checkra.in](https://checkra.in/)
- 対応iOS: 12.0 〜 14.8.1 (一部端末は15系の一部も)
- tethered(USB接続した状態での再適用が必要な場合あり)
- 手持ちの **iPhone 8 Plus (A11)** はこの系統

#### palera1n
- 公式サイト: [palera.in](https://palera.in/)
- GitHub: [palera1n/palera1n](https://github.com/palera1n/palera1n)
- 対応iOS: 15.0 〜 17.x(A8〜A11、checkm8ベースで新しいiOSにも対応)
- rootful / rootless 選択式

## 2. A12以降(arm64e) ソフトウェア脆弱性ベース

A12以降はBootROM脆弱性が(現状)公開されていないため、iOSのソフトウェア脆弱性(カーネル/サンドボックス脱出など)を使った**semi-untethered**脱獄が中心です。

#### Dopamine
- 公式サイト: [ios.cfw.guide – Dopamine](https://ios.cfw.guide/installing-dopamine/)
- GitHub: [opa334/Dopamine](https://github.com/opa334/Dopamine)
- 対応端末: A12〜A17 (iPhone XS以降)
- 対応iOS: バージョンごとに脆弱性が異なるため都度変動(執筆時点で15.0〜16.6.1系が中心)
- rootless方式(iOSのシステム領域を直接改変しないため安定性が高い)

#### kfd (kernel file descriptor) エクスプロイト基盤
- 開発者: [Linus Henze](https://twitter.com/LinusHenze)
- GitHub: [LinusHenze/kfd](https://github.com/LinusHenze/kfd)
- Dopamineなど複数ツールの基盤として使われているカーネル権限昇格技法群

#### Fugu15 / Fugu15 Max
- GitHub: [LinusHenze/Fugu15](https://github.com/LinusHenze/Fugu15)
- 使用脆弱性: physpuppet, PUAF (Physical Use-After-Free) 系
- 対応iOS: 15.0〜15.4.1など限定的

## 6. 注意事項
- 脱獄は自己責任。保証対象外・セキュリティリスク増加の可能性あり
- iOSアップデート前に **SHSH blob** を保存推奨([TSSSaver](https://github.com/airsquared/TSSSaver)等)
- 本記事の対応バージョンは執筆時点のものであり、**実行前に必ず各公式ソースを確認してください**
