# DJI Osmo Pocket 3 シーン別最適設定

DJI Osmo Pocket 3 の各撮影シーンにおける最適設定を、設定理由と操作手順込みで解説します。

---

## 180° シャッター則（基本）

映像のモーションブラーを自然に保つための基本ルール。

| fps | 推奨SS | 用途 |
|-----|--------|------|
| 24fps | 1/50s | 映画的ルック・夜景・インタビュー |
| 30fps | 1/60s | 日常Vlog・旅行・標準 |
| 60fps | 1/120s | スポーツ・スムーズ映像 |
| 120fps | 1/240s | スロー4× |
| 240fps | 1/480s | スロー8×（最大） |

---

## シーン 01 — 日常 Vlog・街歩き

### 推奨設定

| 項目 | 設定値 |
|------|--------|
| 解像度 | 4K 30fps |
| カラー | Normal |
| 手ブレ補正 | RockSteady |
| シャッター | 1/60s |
| ISO | Auto（上限800） |
| WB | Auto |
| ND | ND8〜ND16（屋外） |
| AF | 顔トラッキング ON |
| マイク | 指向性（前方） |

### ポイント

- **カラーはNormal**：D-Log Mは後編集が必要。毎日の記録には撮って出しで完成するNormalが現実的
- **4K撮影の理由**：縦動画（Reels/TikTok）にリフレームする際も解像度が余る
- **屋外ND必須**：f/2.0固定のため晴天でND無しだと露出オーバー。ND8〜16が標準

### NDフィルター目安（30fps用）

| 天候 | 推奨ND |
|------|--------|
| 快晴 | ND32〜ND64 |
| 晴れ | ND16〜ND32 |
| 薄曇り | ND8〜ND16 |
| 曇り | ND4〜ND8 |
| 屋内・夕暮れ | 不要 |

## シーン 02 — 旅行・風景

### 推奨設定

| 項目 | 設定値 |
|------|--------|
| 解像度 | 4K 30fps（24fpsも可） |
| カラー | D-Log M |
| 手ブレ補正 | HorizonSteady |
| シャッター | 1/60s（MF） |
| ISO | Auto（上限400） |
| WB | **マニュアル固定** |
| ND | ND16〜ND64 |
| AF | エリア / MF（遠景） |

### ポイント

- **D-Log M**：空のグラデーション・夕焼けの階調を最大限に記録。LUT（DaVinci Resolve）で仕上げ
- **HorizonSteady**：坂道・斜面でも水平ラインを維持。海の水平線・山の稜線が映える
- **WBはマニュアル固定必須**：D-Log M + Auto WBだとシーンごとにグレーディング設定が狂う

### WB目安

| 環境 | 設定値 |
|------|--------|
| 晴天屋外 | 5500〜5600K |
| 曇り | 6200〜6500K |
| 日陰 | 7000K |

---

## シーン 03 — スポーツ・アクション

### 推奨設定

| 項目 | 設定値 |
|------|--------|
| 解像度 | 4K 60fps |
| カラー | Normal |
| 手ブレ補正 | RockSteady MAX |
| シャッター | 1/250〜1/500s |
| ISO | Auto |
| AF | スポーツAF |

### ポイント

- **4K 60fps**：通常速 + 50%スローの2用途に使える一石二鳥の設定
- **SS 1/250〜1/500**：180°則をあえて破って被写体ブラーを除去
- **スロー最大は1080p 240fps**（8×スロー）

### SS別用途

| シーン | 推奨SS |
|--------|--------|
| ジョギング | 1/120s |
| サイクリング | 1/250s |
| サッカー | 1/500s |
| モータースポーツ | 1/1000s以上 |

---

## シーン 04 — 夜景・暗所

### 推奨設定

| 項目 | 設定値 |
|------|--------|
| 解像度 | 4K 24fps |
| カラー | D-Log M |
| シャッター | 1/50s（固定） |
| ISO | 手動 400〜3200 |
| WB | 手動固定 |
| ND | なし |
| 手ブレ補正 | RockSteady（三脚時OFF） |

### ポイント

- **24fps**：1フレームあたりの露光時間が長く、ISO上昇を抑えられる
- **ISO手動制御**：AutoはISOを上げすぎてノイズだらけになる。400から始めて調整
- **ISO 3200が限界目安**：超えたらDaVinci ResolveのUltra NRでノイズ低減

---

## シーン 05 — インタビュー・トーク

### 推奨設定

| 項目 | 設定値 |
|------|--------|
| 解像度 | 4K 24fps |
| カラー | D-Log M |
| シャッター | 1/50s |
| WB | 手動固定 |
| 手ブレ補正 | OFF（固定）またはRockSteady |
| AF | 顔トラッキング優先 |
| マイク | DJI Mic 2（推奨） |

### ポイント

- **音質最優先**：DJI Mic 2（ワイヤレスラベリアマイク）をUSB-Cに直接接続
- **収録音量**：ピークレベルを-12〜-6dBに設定。0dBで音割れ（修正不可）
- **距離は1.5m以上**：20mm広角レンズは近すぎると顔が歪む
- **ピーク音量設定**：-12〜-6dBで余裕を持たせる

## シーン 06 — タイムラプス・ハイパーラプス

### 推奨設定

| 項目 | 設定値 |
|------|--------|
| モード | Timelapse / Hyperlapse |
| 解像度 | 4K最高画質 |
| カラー | D-Log M |
| WB | **マニュアル固定（必須）** |
| 露出 | **マニュアル固定（必須）** |
| AF | **MF固定（必須）** |
| 電源 | モバイルバッテリー給電 |

### インターバル目安

| 被写体 | 推奨インターバル |
|--------|----------------|
| 日の出・日の入り | 3〜5s |
| 雲の流れ | 2〜3s |
| 街の人の流れ | 1〜2s |
| 植物の成長 | 30〜60s |

> ⚠️ **WB・露出・AFのAuto設定は絶対NG**。フリッカー（点滅）映像になる

---

## シーン 07 — スローモーション

### 推奨設定

| モード | スロー倍率 | 解像度 |
|--------|-----------|--------|
| 4K 120fps | 4× | 4K |
| 1080p 120fps | 4× | 1080p |
| **1080p 240fps** | **8×（最大）** | **1080p** |

### ポイント

- **240fpsは光量が1/8**：屋外昼間か強い照明が必要
- **V30以上のSDカード必須**：速度不足で録画停止の原因になる
- **音声は使えない**：後からBGM・ナレーションをかぶせること前提

---

## シーン 08 — 雨天・悪条件

> ⛔ **Pocket 3はIP防水非対応**。雨天撮影は防水ケース必須

### 雨天推奨設定

| 項目 | 設定値 |
|------|--------|
| 解像度 | 4K 30fps |
| ISO | 手動 400〜1600 |
| WB | 6500〜7000K固定 |
| ND | ND4以下またはなし |

### 水没時の緊急対処

1. 即座に電源OFF（通電し続けるとショート）
2. SDカードを取り出す（データ保護）
3. 外装の水分をクロスで拭き取る
4. シリカゲルを入れた密封袋に本体を入れる
5. 24〜72時間乾燥させる
6. 動作確認後に使用（異常があればDJIサポートへ）
