# MacDock — 自作Tweak

**mikiyan1978**(自分)が開発した、脱獄iOS向けの**macOS風フローティングウィンドウマネージャー**Tweak。任意のアプリをウィンドウとして浮かせ、複数同時表示できる。

[Sileoリポジトリで配布中](https://mikiyan1978.github.io/sileo-repo/)（`com.mikiyan1978.macdock`）

---

## 機能

- 任意のアプリをリサイズ可能なウィンドウとしてフロート表示
- 複数ウィンドウを同時展開
- 画面端へのスナップ(吸着)
- ウィンドウの位置・サイズを記憶
- 信号機ボタン(閉じる／最小化／最大化／復元)
- ヘッダーバー右側にそのアプリ本来のアイコンを表示
- ピンチでリサイズ、または右下ハンドルをドラッグ
- ドラッグで移動
- App Switcher連携(ウィンドウ化中のアプリは上部に縮小表示、二重表示を防止)
- ライブプレビュー付き設定画面

---

## 使い方

### ウィンドウを開く
ホーム画面アイコンを3D Touch(長押し)してメニューから「ウィンドウ化」を選ぶ、またはアプリセレクターパネルからアプリを選択する。

> v1.5.3で、常時表示していた⧉ボタン(マスタースイッチOFFでも表示され続けるバグがあった)を廃止し、ホーム画面アイコンの3D Touchメニューに統合した。

### 信号機ボタン(ヘッダーバー左上)
| 色 | 動作 |
|---|---|
| 🔴 赤 | ウィンドウを閉じる(アプリも終了) |
| 🟡 黄 | 0.6倍に縮小 / 復元 |
| 🔵 青 | ウィンドウ解除してフルスクリーン化 |

### ヘッダーバーのジェスチャー
| 操作 | 動作 |
|---|---|
| シングルタップ | ボタンの表示/非表示切り替え |
| ダブルタップ | 0.6倍に縮小 / 復元 |
| 長押し(0.7秒) | ウィンドウを閉じる |
| ドラッグ | ウィンドウを移動 |

### App Switcher連携
スイッチャーを開いている間、ウィンドウ化中のアプリは上部にアイコンとして縮小表示される。アイコンをタップするとそのアプリが実際にフォアグラウンドになる。

### リサイズ
2本指ピンチ、または右下ハンドルをドラッグ。最小サイズは120pt。掴める範囲は見た目(アイコン表示サイズ)より広め(44pt角)に確保してあり、見た目を変えずに掴みやすくしている。ウィンドウを最小サイズ付近まで縮めてヘッダーの要素(信号機ボタン+アプリアイコン)が重なりそうな幅になったら、隠す代わりに全要素を均等間隔で再配置する。

### 画面端スナップ
端から70pt以内でリリースすると自動吸着(上下左右対応、Dynamic Island考慮済み)。

### ウィンドウ記憶
アプリごとに位置・サイズを記憶し、次回起動時に復元。

### 設定
設定アプリ → MacDock から、ON/OFF・エッジスナップ・位置記憶・ドラッグ時の透明度をリスプリング不要でライブ反映。マスタースイッチOFFにすると3D Touchメニューの「ウィンドウ化」項目も消える。

## 動作要件

- iOS 15.0 以降
- Rootless脱獄(Dopamine)またはRootful脱獄(palera1n, checkra1n)
- MobileSubstrate / Substitute
- iphoneos-arm64(rootless) / iphoneos-arm(rootful)の両方をビルド・配布

```
Package: com.mikiyan1978.macdock
Depends: mobilesubstrate, firmware (>= 15.0)
Version: 1.6.4
Section: Tweaks
Tag: role::developer, compatible_ios16
```

## 実装構成(Theos/Logos)

| ファイル | 役割 |
|---|---|
| `MacDockCore.xm` | コア機能・フック |
| `MacDockHooks.xm` | SpringBoard/アプリへのフック |
| `MacDockWindow.xm` | ウィンドウ管理ロジック |
| `MacDockFloatingWindowView.xm` | フローティングウィンドウのView実装 |
| `MacDockAppButton.xm` | 各アプリに注入、windowize要求を受けてアプリ自身をsuspendするだけの最小限の常駐(別dylib: `MacDockAppButton.dylib`) |
| `MacDockView.h/.m` | ビューのベースクラス |
| `MacDockPref/` | 設定Bundle(設定アプリ連携) |
| `headers/MacDockPrivateAPI.h` | 使用するプライベートAPIヘッダ |

ビルド成果物は `MacDock.dylib` と `MacDockAppButton.dylib` の2本立て。
